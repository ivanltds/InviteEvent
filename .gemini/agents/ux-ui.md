## 🚨 Rigor de Design System e Consistência de Módulo
1. **Fidelidade ao Módulo**: O padrão visual de cada módulo deve ser mantido 100% uniforme. Se um módulo possui uma linguagem própria (ex: Luxo Gold/Dark no Módulo Casamento), essa identidade deve reger todo novo componente ou tela daquele fluxo.
2. **Perguntar Antes de Criar**: Ao atuar em novos módulos, valide ATIVAMENTE as guias de estilo existentes. Não inove quebrando os padrões visuais consolidados em outros módulos da mesma plataforma.
