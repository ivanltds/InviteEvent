# PRD-016: Motor Viral - Experiência do Convidado (Guest Stories) 🚀📸

> **Status:** PIVOTADO / REFINAMENTO  
> **Responsável:** @ba (Analista de Negócios)  
> **Data:** 16 de Maio de 2026  
> **Fase:** Fase 2 - Aquisição Orgânica via Experiência Real

---

## 1. Visão Geral (O Novo Norte)
Abandonamos a ideia de uma ferramenta administrativa para os noivos e focamos na **Experiência do Convidado durante o evento**. O objetivo é que o convidado, ao escanear o QR Code do **Mural Vivo (Modo TV)**, tenha a opção não apenas de enviar fotos para o telão, mas de criar um Story estilizado com a identidade do casamento para postar em suas redes sociais.

---

## 2. User Stories (Revisitadas)

### [US-01] Criação de Story pelo Convidado
**Como** convidado de um casamento,  
**Quero** capturar ou subir uma foto minha com o casal e aplicar um template elegante do evento,  
**Para** compartilhar esse momento no meu Instagram Stories com um visual premium.

*   **Critérios de Aceite:**
    *   Acesso via QR Code único (o mesmo do Mural TV).
    *   Interface mobile ultra-rápida (Web App).
    *   Upload de foto -> Escolha de Template Minimalista -> Renderização de Story.
    *   O template deve conter os nomes do casal, data e identidade visual do casamento.

### [US-02] QR Code Unificado (Mural + Story)
**Como** organizador,  
**Quero** exibir um único QR Code no telão (Modo TV),  
**Para** que os convidados acessem o Mural e o Gerador de Stories em um só lugar.

*   **Critérios de Aceite:**
    *   Página de destino (Mural) ganha um CTA proeminente: "Criar meu Story do Evento".

### [US-03] Templates Minimalistas de Memória
**Como** convidado,  
**Quero** templates que não "poluam" minha foto,  
**Para** que o foco seja a memória compartilhada, com apenas detalhes elegantes da identidade do casal.

---

## 3. Fluxo UX (Mobile-First)

1.  **Scan:** Convidado escaneia o QR Code na TV do evento.
2.  **Landing:** Abre a página do Mural Vivo.
3.  **Escolha:** Botão "✨ Criar Story Personalizado".
4.  **Captura:** Abre câmera ou galeria do celular.
5.  **Overlay:** Sistema aplica automaticamente os nomes dos noivos e a data em tipografia luxo (conforme config do evento).
6.  **Finalização:** Botão "Baixar Story" para postar no Instagram.

---

## 4. Diferencial Competitivo
Ao contrário de filtros de Instagram genéricos, aqui entregamos a **Identidade Visual Exata** que os noivos escolheram para o casamento (Design System Gold, Champagne, etc.), criando uma unidade estética entre o evento físico e o digital.
